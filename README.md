# Портфолио — Анна Шульцева

Статический сайт-портфолио. Одна страница с якорной навигацией по разделам:
герой → лента брендов → обо мне → кейсы Future Today → кейсы фриланс → контакты.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | страница целиком (версия для хостинга) |
| `artifact.html` | та же страница для публикации ссылкой через Claude — правится автоматически из `index.html` |
| `css/styles.css` | все стили, палитра и типографика в блоке `:root` |
| `js/main.js` | мобильное меню и просмотр картинок по клику |
| `img/` | все медиа, переименованные в латиницу |

## Как посмотреть локально

Двойной клик по `index.html` откроет страницу в браузере.
Если нужен полноценный локальный сервер:

```bash
python -m http.server 8123
```

## Что легко поменять

**Палитра и шрифты** — в начале `css/styles.css`, блок `:root`:
`--paper` (фон), `--ink` (тёмно-синий), `--gilt` (золото), `--blue` (акцент ссылок).

**Лента брендов** — в `index.html`, секция `<section class="ribbon">`.
Сейчас это текстовые начертания. Если появятся файлы логотипов, положите их
в `img/logos/` и замените содержимое `<li>` на
`<li><img src="img/logos/sber.svg" alt="Сбер"></li>`.
Список продублирован дважды подряд — это нужно для бесшовной прокрутки,
правки вносятся в обе копии.

**Тексты и цифры кейсов** — блоки `<article class="case">`:
`.stats` — плитки с метриками, `.result` — блок «Результат», `.tasks` — «Что я делала».

**Пропорции картинок** — классы на `<figure class="tile ...">`:
`ar-banner`, `ar-video`, `ar-wide`, `ar-port`, `ar-tall`, `ar-vert`,
плюс `span-all` (на всю ширину) и `span-2` (на две колонки).

## Публикация

Папку целиком можно залить на любой статический хостинг
(GitHub Pages, Netlify, Vercel, Timeweb) — сборка не нужна.
